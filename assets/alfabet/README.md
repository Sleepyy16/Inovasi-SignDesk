# Gambar Isyarat Alfabet BISINDO

Folder ini menyimpan gambar referensi isyarat untuk fitur
**Teks → Isyarat**: ketika petugas mengetik teks, aplikasi
menampilkan urutan gambar huruf isyarat dari folder ini.

## Format File

- Nama file: `A.png`, `B.png`, ..., `Z.png` (huruf kapital)
- Format: PNG (lebih baik, mendukung transparansi) atau JPG
- Ukuran disarankan: minimal 200×200 piksel, rasio 1:1 (kotak)
- Latar: polos/putih agar mudah dibaca

## Status

| Z     | ☐ Belum  | Eksperimental (gerakan) |

> **Penting:** Verifikasi setiap gambar dengan penutur BISINDO asli
> atau referensi resmi sebelum dipakai di aplikasi.
> Jangan mengandalkan gambar yang tidak terverifikasi.

## Cara Mendapatkan Gambar

1. Foto/tangkap layar dari sumber terverifikasi (kamus isyarat BISINDO,
   video PUSAT BAHASA ISYARAT INDONESIA / Gerkatin, dll.)
2. Pastikan lisensi mengizinkan pemakaian untuk riset/pendidikan
3. Catat sumber di README ini
